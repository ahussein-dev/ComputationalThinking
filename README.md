# Computational Thinking

My first ever software project: a three-page static website introducing computational thinking and the codebreaker Joan Clarke, built in HTML and CSS in October 2023 for the Computational Thinking module (CMT119) of my MSc Computing at Cardiff University.

## What's here
- **Introduction to computational thinking:** decomposition, pattern recognition, abstraction and algorithm design, with a worked `sumUp(n)` example comparing an O(n) loop with the O(1) formula
- **Joan Clarke biography:** the Bletchley Park cryptanalyst who worked on breaking Naval Enigma in Hut 8
- **Reflection:** my learning journey moving from Mathematics into Computer Science

## Project history
- **October 2023:** original coursework submission, preserved unedited under the tag [`v1.0-original-submission`](../../tree/v1.0-original-submission)
- **November 2026:** tidied up: fixed typos, factual errors, invalid HTML and CSS, mobile layout and accessibility issues, and corrected my original explanation of the `sumUp` example

## Run it locally
Clone the repo and open `index.html` in your browser. No build step needed.
