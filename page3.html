Course Refelction

Overall, I enjoyed Computational Thinking as my first module of my master's degree. As a mathematics undergrade, it gave me smooth transition into computing and it has equipped me with essential skills that will be invaluable in both my academic and professional journey.

The first concept and perhaps the foundation of this module I encountered was computational thinking. This new found perspective has not only improved my problem-solving skills but also taught me to structure problems more logically. So, whether its programming or real-life problems, computational thinking is now a skill I have at my disposal. I enjoyed solving the JavaScript exercises, as I am a kinetic learning and was able to reaffirm my knowledge about computational thinking and modelling.

This module has sparked my interested in web development and has allowed me to express more of my creative side. I enjoyed drawing out how I wanted my website to look before I started coding, and I enjoyed making changes that no longer fit the original plan. I found myself researching about how HTML and CSS are vital for user-friendly websites. I also like how we learnt JavaScript and html and CSS alongside each other, as I've researched about the application of JavaScript on web design and will be using these skills in later modules on this course.

Learning about computational thinking, JavaScript, HTML and CSS will make it easier to now learn different programming languages especially languages based on the same paradigm, such as Python that I will be using during the fundamentals to programming module.

The lecture timetable was particularly useful. Having the Monday, Wednesday and Friday off make preparing and reviewing lectures very easy. In the future, I hope to use computational thinking to organise out my outside of lecture times to make them more productive. For example write down all the task I need to do(decomposition), highlight which ones are more important and how long they will take (abstraction), and create a more effecient schedule (algorithm design).

If I were to do this module again, I would focus more of my time playing with JavaScript, HTML and CSS rather than watching videos and reading lecture notes. Both were vital for my learning experience but I focus too much energy on understanding what the minor details meant when I could have learnt so much more if I practise for myself.
