Course Reflection

Overall, I enjoyed Computational Thinking as my first module of my master's degree. As a mathematics undergrad, it gave me a smooth transition into computing and it has equipped me with essential skills that will be invaluable in both my academic and professional journey.

The first concept and perhaps the foundation of this module I encountered was computational thinking. This new found perspective has not only improved my problem-solving skills but also taught me to structure problems more logically. So, whether it's programming or real-life problems, computational thinking is now a skill I have at my disposal. I enjoyed solving the JavaScript exercises, as I am a kinaesthetic learner and was able to reaffirm my knowledge about computational thinking and modelling.

This module has sparked my interest in web development and has allowed me to express more of my creative side. I enjoyed drawing out how I wanted my website to look before I started coding, and I enjoyed making changes that no longer fit the original plan. I found myself researching about how HTML and CSS are vital for user-friendly websites. I also like how we learnt JavaScript and HTML and CSS alongside each other, as I've researched about the application of JavaScript on web design and will be using these skills in later modules on this course.

Learning about computational thinking, JavaScript, HTML and CSS will make it easier to now learn different programming languages especially languages based on the same paradigm, such as Python that I will be using during the Fundamentals of Programming module.

The lecture timetable was particularly useful. Having the Monday, Wednesday and Friday off made preparing and reviewing lectures very easy. In the future, I hope to use computational thinking to organise my time outside lectures to make it more productive. For example write down all the tasks I need to do (decomposition), highlight which ones are more important and how long they will take (abstraction), and create a more efficient schedule (algorithm design).

If I were to do this module again, I would focus more of my time playing with JavaScript, HTML and CSS rather than watching videos and reading lecture notes. Both were vital for my learning experience but I focused too much energy on understanding what the minor details meant when I could have learnt so much more if I had practised for myself.
